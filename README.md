# 深圳市居民就餐调查配额领取网页

这是一个供调查员领取深圳市居民就餐调查任务的公开网页。调查员可以按居住地、年龄、学历等配额选择受访者，并提交姓名、学校/单位和联络手机号。

## 在线使用

https://shenzhen-survey-quota.ssee6416.chatgpt.site/

## 主要规则

- 每次领取 5 名受访者。
- 选择 18–24 岁或 25–34 岁受访者时，需要搭配 35–44 岁、45–59 岁或 60 岁及以上受访者。
- 选择大专及以上学历受访者时，需要搭配初中及以下或高中/中专学历受访者。
- 某一配额用完后不能继续选择。
- 前端仅显示领取者姓名；悬停或点击姓名后显示学校/单位和联络手机号。

## 技术说明

项目使用 Next.js/vinext 和 Cloudflare D1。GitHub 保存公开源码；在线网页继续由 Sites 托管，因为配额扣减和领取记录需要数据库，不能直接用纯静态 GitHub Pages 替代。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```
